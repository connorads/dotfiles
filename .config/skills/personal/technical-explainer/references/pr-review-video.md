# PR Review Video

The video should leave a colleague ready to review the proposal. Its runtime,
visual style and narration support that outcome.

## Prepare The Story

Use the agreed project location and preserve existing versions. Keep video
production files outside the source checkout unless the user chooses otherwise.

Read the PR description, relevant changed files and evidence behind the claims.
Record the inspected revision. Use the host's PR tooling for this evidence;
browser footage is useful only when seeing an interaction explains the change.

Draft the spoken explanation before building the scenes. Give each scene one
question to answer and one focal visual. Use the worked example to connect the
proposal to something the viewer recognises.

For an evaluation, explain the inputs, comparison and scoring before the result.
For example, "We asked an agent to review saved changes from old PRs, with and
without the rules. We compared its suggestions with the original comments."
Only use this description when the evidence supports that procedure.

## Audition The Narration

Use an accepted voice choice when one exists. Otherwise make short samples
before generating the full narration. Include names and technical terms from
the script so the sample tests pronunciation as well as tone.

Offer a small choice suited to the user's requested style. If the user delegates
the choice, state the selection and proceed. If they request approval of the
sample, wait for their answer before generating the full narration.

Keep pronunciation instructions separate from visible spelling. For example,
a spoken alias can pronounce a company name correctly while captions retain
its written name. Do not carry a particular voice or accent into unrelated briefs.

## Make Time For Understanding

Break narration into meaningful beats. Derive scene timing from the generated
audio, with explicit silent gaps between ideas and longer holds between sections.
Listen to the pauses in context and adjust them to the amount on screen.

When the video exceeds its target length, cut secondary material before speeding
up the voice or removing reading time. A duration check cannot tell whether the
viewer can follow the explanation.

Reveal a visual when its narration introduces it. Show the relevant code or
comparison rather than a full PR page that the viewer must search. Keep captions
clear of code, labels and source references.

## Verify The Export

Use the renderer's checks, then inspect the actual exported file. Sample every
scene and its transitions for clipping, overlap, legibility and caption timing.
Listen for pronunciation, abrupt cuts and missing pauses. A transcript can catch
missing words; it cannot establish that a name sounds right.

Recheck the closing review route against the source material. Deliver the video
with its editable project and script. Report which checks ran and any material
checks that remain.
